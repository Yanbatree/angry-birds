# 愤怒的小鸟 · Angry Birds（网页版）

零依赖的单文件 Canvas 游戏：**双击 `index.html` 即可游玩**，也可以直接玩线上版：
👉 https://yanbatree.github.io/angry-birds/

## 玩法

- 按住弹弓上的小鸟拖拽，松开发射（有白色弹道预览）
- 飞行中**点击屏幕**触发技能：
  - 🔴 红鸟：普通
  - 🟡 黄鸟：加速冲刺
  - 🔵 蓝鸟：分身 ×3
  - ⚫ 黑鸟：爆炸
- 打碎所有积木、消灭全部小猪过关；剩余小鸟越多星级越高
- 5 个手工关卡 + 通关后解锁随机生成的**无尽模式**
- **选关系统**：通关自动存档（localStorage），可反复刷关刷星
- 快捷键：`R` 重开本关，`N` 胜利后进入下一关

## 技术

- 纯 HTML5 Canvas，无任何外部依赖（音效由 WebAudio 实时合成）
- 手写 2D 物理引擎：冲量/角动量求解器、圆-圆 / 圆-OBB / OBB-OBB（SAT）碰撞检测、双接触点耦合冲量求解（堆叠稳定）、按撞击速度判定伤害的破坏系统
- 所有关卡初始布置经过离线物理仿真验证（静置零位移、零误伤）

## 本地运行

用浏览器打开 `index.html` 即可；或在目录下起一个静态服务器：

```bash
python -m http.server 8000
# 或
npx serve .
```

然后访问 http://localhost:8000
